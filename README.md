## Projects

### [TaskFlow](https://github.com/AdithyaKammara/taskflow) · [Live app](https://adithyakammara.github.io/taskflow/)

A team task manager with accounts, shared workspaces and live sync. Written in plain HTML, CSS and JavaScript with no framework; Supabase handles auth, Postgres and realtime.

- List, drag-and-drop board and calendar views; a dashboard with hand-built SVG charts
- Natural-language quick add (`Review PR tomorrow @priya #dev !high`), undo/redo, command palette, keyboard shortcuts
- Invite links, workspace switching, and teammates' edits appearing in about a second
- 61 unit tests, ESLint + Prettier, CI on every push, deployed with GitHub Actions to Pages

`JavaScript` `Supabase` `PostgreSQL` `GitHub Actions`

### [Food Munch](https://github.com/AdithyaKammara/Food-Munch-) · [Live demo](https://foodmunch-app.vercel.app)

A food-ordering frontend inspired by Hyderabad's food culture: dish search and filters, portion and spice customisation, a persistent cart with promo codes, validated checkout and a simulated order tracker.

- Typed cart and order state with Zustand, persisted in the browser
- 48 tests with Vitest and Testing Library, linted and type-checked in CI
- GSAP motion that respects reduced-motion settings

`React 19` `TypeScript` `Vite` `Tailwind CSS` `Vitest`

### [AI Ticketing](https://github.com/AdithyaKammara/ai-ticketing)

An internal support desk where an LLM reads each new ticket, categorises it, scores sentiment, auto-answers simple ones and routes the rest to the right department, picking an assignee by weighing skill match against current workload.

- FastAPI + SQLAlchemy backend with ticket timelines, notes, feedback and analytics endpoints
- Next.js admin dashboard with filters and Recharts analytics
- Groq (Llama 3.3 70B) for classification and auto-responses

`Python` `FastAPI` `SQLite` `Next.js` `Groq`

### [Data Analyst Assignment](https://github.com/AdithyaKammara/Data_Analyst_Assignment)

Hiring assignment for PlatinumRx covering SQL, spreadsheets and Python: schema design and ten analytical queries for hotel and clinic datasets (CTEs, `RANK`/`DENSE_RANK` window functions, monthly profit roll-ups), a ticket-analysis workbook, and two Python utilities.

`SQL` `Window functions` `Excel` `Python`
